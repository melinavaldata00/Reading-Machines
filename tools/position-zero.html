using the exported JSON in InDesign

The ↓ json export contains every visible word box (position, size, rotation, recognised text, OCR confidence) plus a font/tracking/leading/opacity recipe per box, driven by that confidence. It's meant to be read by a script, not edited by hand — but here's what's inside it and how to turn it into an InDesign layout automatically.

json fields

canvas.w / .hsize of the source image in px — used as the page size
frames[].x / y / w / hunrotated bounding box of the word, in px
frames[].rotationdegrees to rotate that box around its own center
frames[].textthe word Tesseract recognised
frames[].confOCR confidence, 0–100
frames[].arizonafont / size offset / tracking / leading % / opacity % for this word, chosen from its confidence
frames[].thread_nextid of the next frame in reading order — used to thread the text frames together

how to run the import script

  1. Download ocr-skeleton-import.jsx below.
  2. In InDesign: Window → Utilities → Scripts to open the Scripts panel.
  3. File → Scripts → Other Script… and pick the downloaded .jsx file directly (no need to install it into the Scripts panel for a one-off run).
  4. Pick the exported ocr-skeleton.json when prompted — the script creates a new document sized to the original image and places every word as a threaded, styled text frame automatically.

The four fonts referenced in arizona (ABC Arizona Serif / Text / Mix / Sans, Trial cuts) need to be installed for the styling to apply — anything missing is left in InDesign's default font and listed in a summary once the script finishes. Everything happens in a single undo step.
