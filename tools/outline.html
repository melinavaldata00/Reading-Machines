how blind contour works

This tool doesn't read anything — no OCR, no text recognition. It's "blind" on purpose: the image is sent to a small hosted Python server that traces the raw shape boundaries in it using OpenCV, the same way you'd trace edges in any computer-vision pipeline, with no idea any of it might be letters.

Server-side, for every uploaded image: convert to grayscale, blur slightly, threshold it two ways (dark-on-light and light-on-dark, via Otsu's method) and keep whichever version finds more contours, clean up the result with a small morphological opening pass, then trace every remaining outline with OpenCV's contour finder. Each traced shape comes back as a path — position, size, and the actual point-by-point outline.

parameters

letterminimum contour area to keep — raise it to discard small noise and keep only larger shapes; lower it to pick up fine detail

Everything you see is that raw contour data rendered back as SVG — there's no interpretation of what the shapes are, just their outlines.
